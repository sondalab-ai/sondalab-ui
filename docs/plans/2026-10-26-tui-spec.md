Repo: sondalab-ui (GitHub sondalab-ai/sondalab-ui). Base: main at 77140ea (ui-kit 0.39.0, pixel direction D).
Existing spec to extend: `docs/tui-patterns.md` (0.38). Tokens: `terminal` and `tui` sections of `sondalab.tokens.json`.
Public kit page: sondalab-site `src/pages/design-system.astro`, which renders `packages/ui-kit/agent/catalog.md` live.

## Approved by the owner: D1, D2, D4, D5, D6, D7, D8 as proposed; D3 with a new spinner

- **D1 Where it lives.** `docs/tui-patterns.md` grows into the full Term spec, in six sections: Voice, Motion, Effects, Patterns (line output), Patterns (full screen), Robustness. New values go into the `tui` tokens: spinner frames and interval, motion durations, the decode glyph set, the dither ramp, the env var names. They reach Python through `sondalab_palette`. In the `design-language.md` matrix, the Term column changes from N/A to A for L4 motion and for L6 glitch.
- **D2 Voice.** L5 as written; measured figures over adjectives.
  - A running step is a present participle ("Resolving q-8f2a…"); a finished one is past tense ("Resolved 3 probes"). Sentence case, no trailing period.
  - Errors take 3 lines: what (after `✗`), why (`dim`, with the exit code or timeout), fix (`Try:` + a command, optionally a docs link with an error code). The fix comes last.
  - "Did you mean" suggests and never runs. Success says what changed and the next step; a silent success is a defect.
  - Banned: emoji, "Oops", "Successfully", exclamation marks, "we". Address the user only in prompts. Stack traces only with `--debug`.
- **D3 Motion.**
  - Respond within 100ms. Show the spinner only after 300ms (our call). A spinner always ends in a persisted step line.
  - Progress is a 24-cell bar whose leading edge dithers `░ ▒ ▓` before `█`, followed by the count and the percentage.
  - Redraw at most 10 fps, changed cells only, in synchronized output (mode 2026) where the terminal supports it.
  - Motion is off for non-TTY, `CI`, `TERM=dumb`, `SONDALAB_REDUCED_MOTION=1` and accessible mode. Static text replaces it.
  - **Spinner, owner 2026-10-26: A, the cycling dither burst** (like the primary button's dither hover). The glyph cell fills and drains, ` ░▒▓█▓▒░`, 8 frames at 100ms (0.8s per cycle), in `prompt`. One column wide, so the step-list grid holds. Rejected: A2, a 3-cell wave after the label, and Q, the quadrant spinner.
- **D4 Glitch → decode.** Same meaning as L6: something re-resolved.
  - Only the changed token decodes, left to right, through 4 frames of `░▒▓█▚▞` plus random ASCII. 60ms per frame, under 300ms, once.
  - No inverse or blink, so no flash. Off in the same cases as motion.
- **D5 Pixel text.**
  - The dither ramp is `░▒▓█`, with the ASCII fallback `. : #`. Only the signal strip and progress use it.
  - The lockup is text: `sonda/lab`, with the slash in `prompt`. No ASCII-art banners.
  - Pixel graphics (half blocks, sextants, braille, sixel, kitty) are for data only, behind a capability check, with a text fallback.
  - Every glyph is one column wide; no emoji.
- **D6 Full-screen patterns.**
  - Rounded light box drawing `╭─╮`. The focused pane has its border in `prompt` and its title in inverse video; other panes are `dim`.
  - Selection is a row tint plus a `▌` seam in `prompt`.
  - Tables have no vertical rules; headers are `dim` uppercase; the identifier comes first.
  - One footer for key hints: keys in `accent`, verbs in `dim`, joined by `·`. Keys: `/` filter, `:` command, `?` help, `q`/`esc` back, `ctrl-c` quit.
  - Destructive actions ask `[y/N]`; an irreversible delete asks the user to type the name. Empty states are one line.
  - Every full-screen view also has `--plain`.
- **D7 Robustness.**
  - Colour precedence: `--color`/`--no-color` flag, then `NO_COLOR`, then `FORCE_COLOR`, then TTY detection and `TERM=dumb`.
  - ANSI 16 by default. Truecolor only when `COLORTERM` is `truecolor` or `24bit` AND the program opts in.
  - Query OSC 11 with a 100ms timeout before any key reader; no reply means dark.
  - `SONDALAB_ACCESSIBLE=1` (and `ACCESSIBLE`) gives plain prompts and no redraw, and implies reduced motion. `SONDALAB_REDUCED_MOTION=1` turns the motion off.
  - Wrap at the terminal width, capped at 100 columns; cut labels at `labelWidth`.
  - On Windows, enable VT processing or fall back to plain text.
  - `--json` for scripts. Progress goes to stderr, results to stdout.
- **D8 Kit page and slices.** A "Terminal" section on sondalab.eu/design-system, generated from `catalog.md` code examples painted with the `terminal` tokens. The motion blocks honour `prefers-reduced-motion`.
  - Slices:
    - **T1:** the spec, the matrix change, the tokens and the tests.
    - **T2:** the `sondalab_palette` constants, plus an optional reference helper for the spinner, progress and decode.
    - **T3:** the catalog Term section and the `showcase` blocks, released as ui-kit 0.40.0.
    - **T4** (sondalab-site repo, after 0.40.0 is on npm): bump `@sondalab/ui-kit` to `^0.40.0` and add the "Terminal" section to `src/pages/design-system.astro`.
  - Model mix (owner CLAUDE.md): Opus authors, one Sonnet review per slice. One integration branch, short slice PRs into it, one merge.
